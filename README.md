Diabetes Prediction Using Random Forest

Project Overview

This project implements a Machine Learning model to classify diabetes categories using the Random Forest Classifier.

Dataset Information

- Total Records: 1,000
- Total Attributes: 14
- Target Variable: CLASS
- Classification: N, P, Y

Machine Learning Algorithm

Random Forest Classifier

Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

Model Evaluation

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- ROC-AUC
